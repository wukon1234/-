## 一、项目概述

### 1.1 项目背景

本项目是一个**商城智能助手系统**，旨在为用户提供智能化的购物体验。系统集成了大语言模型（LLM）和检索增强生成（RAG）技术，能够理解用户自然语言查询，提供商品推荐、订单查询、物流追踪等智能服务。

### 1.2 项目目标

- 提供智能化的购物助手服务
- 支持自然语言交互
- 实现商品智能推荐
- 提供订单查询与物流追踪
- 支持多轮对话会话管理
- 提供管理后台配置能力

### 1.3 项目结构

```
mall-project/
├── mall-backend/          # 后端服务
│   ├── src/main/java/     # Java源代码
│   ├── src/main/resources/# 配置文件
│   └── pom.xml            # Maven配置
├── mall-frontend/         # 前端应用
│   ├── src/               # Vue源代码
│   └── package.json       # npm配置
└── docs/                  # 文档
```

```java
public static String generateToken(Long userId, String username) {
    Date now = new Date();
    Date expirationDate = new Date(now.getTime() + EXPIRATION);
    
    return Jwts.builder()
            .setSubject(String.valueOf(userId))
            .claim("username", username)
            .setIssuedAt(now)
            .setExpiration(expirationDate)
            .signWith(SignatureAlgorithm.HS512, SECRET)
            .compact();
}
```

```java
// JwtInterceptor.java
public boolean preHandle(HttpServletRequest request, HttpServletResponse response, Object handler) {
    String token = request.getHeader("Authorization");
    if (token != null && token.startsWith("Bearer ")) {
        token = token.substring(7);
        try {
            Claims claims = JwtUtil.parseToken(token);
            Long userId = Long.parseLong(claims.getSubject());
            request.setAttribute("userId", userId);
            return true;
        } catch (Exception e) {
            log.warn("Token验证失败: {}", e.getMessage());
        }
    }
    return true; // 不强制拦截，由Controller判断是否需要登录
}
```

```java
public List<Product> searchProducts(String query, int topK) {
    log.info("RAG检索商品，查询: {}, topK: {}", query, topK);
    
    // 优先使用向量检索
    if (shouldUseVectorSearch()) {
        List<Map<String, Object>> results = vectorSearchProducts(query, topK);

                .filter(Objects::nonNull)
```

**向量检索实现**：

```java
private List<Map<String, Object>> vectorSearchProducts(String query, int topK) {
    try {
        // 生成查询向量
        List<Float> qVec = embeddingService.embed(query);
        if (qVec == null || qVec.isEmpty()) return new ArrayList<>();
        
        // 查询向量数据库
        List<String> ids = vectorStore.query(qVec, topK);
        if (ids == null || ids.isEmpty()) return new ArrayList<>();
        
        // 从MySQL获取完整商品数据
        List<Long> productIds = ids.stream()
            .map(id -> {
                try { return Long.parseLong(id); } 
                catch (Exception e) { return null; }
            })
            .filter(Objects::nonNull)
            .collect(Collectors.toList());
        
        List<Product> products = productMapper.selectBatchIds(productIds)
            .stream()
            .filter(p -> p != null && p.getStatus() != null && p.getStatus() == 1)
            .collect(Collectors.toList());
        
        // 保持返回顺序与向量检索结果一致
        Map<Long, Product> map = products.stream()
            .collect(Collectors.toMap(Product::getId, p -> p));
        
        List<Map<String, Object>> result = new ArrayList<>();
        for (Long pid : productIds) {
            Product p = map.get(pid);
            if (p != null) result.add(productToMap(p));
        }
        return result;
    } catch (Exception e) {
        log.warn("向量检索失败，降级关键词检索: {}", e.getMessage());
        return new ArrayList<>();
    }
}
```

```java
// CartServiceImpl.java
public void addCart(Long userId, AddCartRequest request) {
    // 检查商品是否存在
    Product product = productMapper.selectById(request.getProductId());
    if (product == null || product.getStatus() != 1) {
        throw new BusinessException(ResultCode.PRODUCT_NOT_FOUND);
    }
    
    // 检查库存
    if (product.getStock() < request.getQuantity()) {
        throw new BusinessException(ResultCode.INSUFFICIENT_STOCK);
    }
    
    // 检查是否已存在
    Cart existing = cartMapper.selectOne(
        new LambdaQueryWrapper<Cart>()
            .eq(Cart::getUserId, userId)
            .eq(Cart::getProductId, request.getProductId())
    );
    
    if (existing != null) {
        // 更新数量
        existing.setQuantity(existing.getQuantity() + request.getQuantity());
        cartMapper.updateById(existing);
    } else {
        // 添加新记录
        Cart cart = new Cart();
        cart.setUserId(userId);
        cart.setProductId(request.getProductId());
        cart.setQuantity(request.getQuantity());
        cartMapper.insert(cart);
    }
}
```

**创建订单**：

```java
// OrderServiceImpl.java
@Transactional
public OrderDTO createOrder(Long userId, CreateOrderRequest request) {
    // 获取购物车商品
    List<Cart> cartItems = cartMapper.selectBatchIds(request.getCartItemIds());
    if (cartItems.isEmpty()) {
        throw new BusinessException(ResultCode.CART_EMPTY);
    }
    
    // 验证并计算总价
    BigDecimal totalAmount = BigDecimal.ZERO;
    List<OrderItem> orderItems = new ArrayList<>();
    
    for (Cart cart : cartItems) {
        Product product = productMapper.selectById(cart.getProductId());
        if (product == null || product.getStatus() != 1) {
            throw new BusinessException(ResultCode.PRODUCT_NOT_FOUND);
        }
        if (product.getStock() < cart.getQuantity()) {
            throw new BusinessException(ResultCode.INSUFFICIENT_STOCK);
        }
        
        // 扣减库存
        product.setStock(product.getStock() - cart.getQuantity());
        productMapper.updateById(product);
        
        // 计算金额
        BigDecimal itemAmount = product.getPrice().multiply(BigDecimal.valueOf(cart.getQuantity()));
        totalAmount = totalAmount.add(itemAmount);
        
        // 创建订单项
        OrderItem orderItem = new OrderItem();
        orderItem.setProductId(product.getId());
        orderItem.setProductName(product.getName());
        orderItem.setPrice(product.getPrice());
        orderItem.setQuantity(cart.getQuantity());
        orderItems.add(orderItem);
    }
    
    // 创建订单
    Order order = new Order();
    order.setOrderNo(generateOrderNo());
    order.setUserId(userId);
    order.setTotalAmount(totalAmount);
    order.setAddressId(request.getAddressId());
    order.setStatus(0); // 待支付
    orderMapper.insert(order);
    
    // 批量插入订单项
    for (OrderItem item : orderItems) {
        item.setOrderId(order.getId());
        orderItemMapper.insert(item);
    }
    
    // 清空购物车
    cartMapper.deleteBatchIds(request.getCartItemIds());
    
    return convertToDTO(order, orderItems);
}
```

```java
// OrderChatIntent.java
public final class OrderChatIntent {
    
    private static final Pattern ORD_NO_PATTERN = Pattern.compile("(?i)\\b(ORD\\d+)\\b");
    private static final Pattern LABELED_ORDER_NO = Pattern.compile("订单号\\s*[:：]?\\s*([A-Za-z0-9\\-]+)");
    
    public static boolean shouldRetrieveOrderData(String query) {
        if (query == null) return false;
        String q = query.trim();
        if (q.isEmpty()) return false;
        
        // 排除"如何下单"等流程问题
        if (isOrderHowToQuestion(q)) return false;
        
        // 匹配订单号
        if (ORD_NO_PATTERN.matcher(q).find()) return true;
        if (LABELED_ORDER_NO.matcher(q).find()) return true;
        
        // 匹配订单相关关键词
        if (q.contains("我的订单")) return true;
        if (q.contains("订单状态")) return true;
        if (q.contains("物流") || q.contains("快递")) return true;
        if (q.contains("发货")) return true;
        if (q.contains("到哪了")) return true;
        if (q.contains("订单号")) return true;
        if (q.contains("查订单")) return true;
        
        return false;
    }
    
    private static boolean isOrderHowToQuestion(String q) {
        return q.contains("如何下单") || q.contains("怎么下单") || 
               q.contains("下单流程") || q.contains("订单流程");
    }
}
```

```java
    assistantService.chatStream(userId, chatRequest, new AssistantService.StreamCallback() {
        @Override
        public void onMessage(String chunk) {
            try {
                emitter.send(SseEmitter.event().name("message").data(chunk));
            } catch (IOException e) {
                emitter.completeWithError(e);
            }
        }
        
        @Override
        public void onComplete() {
            try {
                emitter.send(SseEmitter.event().name("message").data("[DONE]"));
                emitter.complete();
            } catch (IOException e) {
                emitter.completeWithError(e);
            }
        }
        
        @Override
        public void onError(Exception e) {
            try {
                emitter.send(SseEmitter.event().name("error").data(e.getMessage()));
            } catch (IOException ex) {}
            emitter.completeWithError(e);
        }
        
        @Override
        public void onProducts(List<Product> products) {
            try {
                Map<String, Object> productsData = new HashMap<>();
                productsData.put("products", products);
                emitter.send(SseEmitter.event().name("message")
                    .data(JSON.toJSONString(productsData)));
            } catch (IOException e) {
                log.error("发送商品推荐失败", e);
            }
        }
    });
    
    return emitter;
}
```

```typescript
// assistant.ts
export const chatStreamPost = async (
  data: ChatRequest,
  onMessage: (chunk: string) => void,
  onDone: (relatedProducts?: Product[], relatedOrders?: RelatedOrderRow[]) => void,
  onError: (error: Error) => void,
  abortController?: AbortController
) => {
  try {
    const token = localStorage.getItem('token');
    
    const response = await fetch('/api/assistant/chat/stream', {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
        'Authorization': token ? `Bearer ${token}` : '',
        'userId': localStorage.getItem('userId') || '1'
      },
      body: JSON.stringify(data),
      signal: abortController?.signal
    });

    const reader = response.body?.getReader();
    const decoder = new TextDecoder();
    
    let buffer = '';
    let relatedProducts: Product[] | undefined;
    let relatedOrders: RelatedOrderRow[] | undefined;

    while (true) {
      const { done, value } = await reader!.read();
      
      if (done) {
        onDone(relatedProducts, relatedOrders);
        break;
      }

      buffer += decoder.decode(value, { stream: true });
      const lines = buffer.split('\n');
      buffer = lines.pop() || '';

      for (const line of lines) {
        if (line.startsWith('data:')) {
          const messageData = line.slice(5).replace(/^\s/, '');
          if (messageData.trim() === '[DONE]') {
            onDone(relatedProducts, relatedOrders);
            return;
          }
          
          try {
            const jsonData = JSON.parse(messageData);
            if (jsonData.products) relatedProducts = jsonData.products;
            if (jsonData.orders) relatedOrders = jsonData.orders;
            if (jsonData.chunk) onMessage(jsonData.chunk);
          } catch {
            onMessage(messageData);
          }
        }
      }
    }
  } catch (error) {
    onError(error as Error);
  }
};
```

### 6.1 JWT认证实现

#### 6.1.1 Token生成与解析

```java
// JwtUtil.java
public class JwtUtil {
    
    private static final String SECRET = "mall-secret-key-2024-secure-token-key";
    private static final long EXPIRATION = 86400000L; // 24小时
    
    public static String generateToken(Long userId, String username) {
        return Jwts.builder()
                .setSubject(String.valueOf(userId))
                .claim("username", username)
                .setIssuedAt(new Date())
                .setExpiration(new Date(System.currentTimeMillis() + EXPIRATION))
                .signWith(SignatureAlgorithm.HS512, SECRET)
                .compact();
    }
    
    public static Claims parseToken(String token) {
        return Jwts.parser()
                .setSigningKey(SECRET)
                .parseClaimsJws(token)
                .getBody();
    }
```

```java
// OrderRAGDataSource.java
public List<Map<String, Object>> search(String query, int topK, Map<String, Object> filters) {
    if (filters == null || !(filters.get("userId") instanceof Number)) {
        return Collections.emptyList();
    }
    
    long userId = ((Number) filters.get("userId")).longValue();
    
    // 意图识别
    if (!OrderChatIntent.shouldRetrieveOrderData(query)) {
        return Collections.emptyList();
    }
    
    // 提取订单号
    Set<String> orderNos = extractOrderNumbers(query);
    
    if (!orderNos.isEmpty()) {
        List<Map<String, Object>> out = new ArrayList<>();
        for (String orderNo : orderNos) {
            Order order = orderMapper.selectOne(
                new LambdaQueryWrapper<Order>()
                    .eq(Order::getUserId, userId)
                    .eq(Order::getOrderNo, orderNo)
            );
            if (order != null) {
                out.add(toOrderMap(order, userId));
            } else {
                out.add(orderNotFoundMap(orderNo));
            }
        }
        return out;
    }
    
    // 返回最近订单
    List<Order> recent = orderMapper.selectList(
        new LambdaQueryWrapper<Order>()
            .eq(Order::getUserId, userId)
            .orderByDesc(Order::getCreateTime)
            .last("LIMIT " + topK)
    );
    return recent.stream().map(o -> toOrderMap(o, userId)).collect(Collectors.toList());
}
```

```java
            if (text != null && !text.isEmpty()) {

            }

        return "抱歉，我暂时无法回答您的问题，请稍后再试。";
```

```java
// AssistantServiceImpl.java
public void chatStream(Long userId, ChatRequest request, StreamCallback callback) {
    new Thread(() -> {
        try {
            // 获取会话
            Conversation conversation = getOrCreateConversation(userId, request.getSessionId());
            
            // 保存用户消息
            saveMessage(conversation.getId(), 1, request.getMessage(), null, null);
            
            // 检查管理端配置
            String managedReply = resolveManagedReply(request.getMessage());
            if (managedReply != null) {
                streamBySemanticUnits(managedReply, callback);
                saveMessage(conversation.getId(), 2, managedReply, null, null);
                callback.onComplete();
                return;
            }
            
            // RAG检索
            List<Product> relatedProducts = ragService.searchProducts(request.getMessage(), 5);
            List<Map<String, Object>> relatedOrders = ragService.searchUserOrders(userId, request.getMessage(), 5);
            
            // 构建提示词
            String prompt = buildPrompt(request.getMessage(), relatedProducts, relatedOrders, conversation.getId());
            
            // 获取历史对话
            List<Map<String, String>> history = getHistoryMessages(conversation.getId(), 10);
            
            // 流式调用LLM
            StringBuilder fullResponse = new StringBuilder();
            llmService.chatStream(prompt, history, new LLMService.StreamCallback() {
                @Override
                public void onMessage(String chunk) {
                    if (chunk == null || chunk.isEmpty()) return;
                    fullResponse.append(chunk);
                    streamBySemanticUnits(chunk, callback);
                }
                
                @Override
                public void onComplete() {
                    String assistantReply = fullResponse.toString();
                    List<Long> productIds = extractProductIds(relatedProducts);
                    saveMessage(conversation.getId(), 2, assistantReply, productIds, relatedOrders);
                    
                    if (relatedOrders != null && !relatedOrders.isEmpty()) {
                        callback.onOrders(relatedOrders);
                    }
                    if (relatedProducts != null && !relatedProducts.isEmpty()) {
                        callback.onProducts(relatedProducts);
                    }
                    
                    callback.onComplete();
                }
            });
        } catch (Exception e) {
            callback.onError(e);
        }
    }).start();
}
```

## 八、业务流程分析

### 8.1 智能对话流程

```
用户发送消息
    ↓
JWT验证（JwtInterceptor）
    ↓
获取/创建会话（Conversation）
    ↓
意图识别（OrderChatIntent）
    ↓
RAG检索（商品 + 订单）
    ├─ 商品检索（关键词/向量）
    └─ 订单检索（用户订单）
    ↓
构建提示词（Prompt Engineering）
    ↓
调用LLM（通义千问）
    ↓
保存消息记录（ConversationMessage）
    ↓
返回响应（普通/流式）
```

### 8.2 订单创建流程

```
用户提交订单请求
    ↓
验证用户身份（JWT）
    ↓
查询购物车商品（Cart）
    ↓
检查库存（Product.stock）
    ↓
扣减库存（更新Product）
    ↓
生成订单号（ORD + 时间戳 + 随机数）
    ↓
创建订单记录（Order）
    ↓
创建订单项（OrderItem）
    ↓
清空购物车（删除Cart）
    ↓
返回订单信息（OrderDTO）
```

### 8.3 用户登录流程

```
用户输入用户名密码
    ↓
验证用户名密码（UserService.login）
    ├─ 查询用户（UserMapper.selectOne）
    └─ 验证密码（BCrypt.matches）
    ↓
生成JWT Token（JwtUtil.generateToken）
    ↓
返回Token（LoginResponse）
    ↓
前端保存Token（localStorage）
```

### 9.1 RAG检索增强

- **多数据源支持**：支持商品、订单等多种数据源，可扩展
- **混合检索模式**：关键词检索 + 向量检索，支持降级策略

- **SSE实时推送**：Server-Sent Events实现实时流式回复
- **语义单元推送**：中文按单字、英文按整词，避免拆碎英文词
- **超时处理**：60秒超时，自动断开连接

### 9.3 管理端配置

- **智能助手开关**：一键启用/停用智能助手
- **回复模式切换**：智能模式/模板模式
- **关键词模板管理**：添加/编辑/删除回复模板

### 9.4 安全性

- **JWT无状态认证**：不依赖Session，便于水平扩展
- **密码BCrypt加密**：安全的密码存储方式
- **全局异常处理**：统一错误响应格式
- **请求参数校验**：JSR-303验证注解

### 9.5 模块化设计

- **接口抽象**：定义统一接口，便于扩展
- **依赖注入**：Spring DI降低耦合度
